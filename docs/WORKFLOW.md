# Рабочий процесс: от трека до готовых рилсов

Подробно, по шагам. Правила — в [../rules.md](../rules.md).

---

## Шаг 0. Что подготовить

На каждый трек нужно три вещи:

1. **Аудио** — `mp3`, `wav`, `flac`, `m4a`. Лучше без сжатия, но mp3 тоже годится.
2. **Обложка** — `jpg`/`png`, желательно квадрат от 1000×1000. Если обложка
   вшита в теги файла, она подхватится сама.
3. **Текст** — обычный `.txt`, по одной строке песни на строку файла.
   Пустые строки и строки, начинающиеся с `#`, игнорируются.

Разложите так:

```
input/
  nochnoy-reys/
    track.mp3
    cover.jpg
    lyrics.txt
```

---

## Шаг 1. Посмотреть, что в треке

```bash
python3 -m ytclip analyze input/nochnoy-reys/track.mp3
```

Покажет темп, количество битов и тактов, сколько процентов времени поёт голос
и какие куски самые цепляющие. Это полезно до рендера: если темп определился
неправильно (бывает на треках без выраженной доли), движение графики будет
мимо музыки.

---

## Шаг 2. Свести текст с музыкой

```bash
python3 -m ytclip align input/nochnoy-reys/track.mp3 --lyrics input/nochnoy-reys/lyrics.txt
```

Получится `work/nochnoy-reys/timing.lrc` — тот самый файл, где видно, какое
слово в какую секунду поётся.

**Откройте его и проверьте глазами.** Формат простой:

```
[00:12.40]<00:12.40>ночь <00:12.95>горит <00:13.60>неоном
```

Квадратные скобки — начало строки, угловые — начало каждого слова. Время можно
править руками, это штатный путь.

Если всё съехало одинаково — не правьте вручную, используйте сдвиг:

```bash
python3 -m ytclip reels ... --offset -0.3
```

---

## Шаг 3. Сделать клипы

```bash
python3 -m ytclip reels input/nochnoy-reys/track.mp3 \
  --cover input/nochnoy-reys/cover.jpg \
  --lyrics work/nochnoy-reys/timing.lrc \
  --title "Ночной рейс" --artist "Название группы" \
  --count 4 --length 22
```

Что произойдёт:

1. анализ трека (темп, биты, вокал);
2. палитра из обложки;
3. тайминг слов;
4. выбор 4 лучших фрагментов, каждый начинается с доли такта;
5. на каждый фрагмент — свой шаблон, рендер в Remotion, затем ffmpeg подмешивает
   звук.

Результат: `out/nochnoy-reys/*.mp4` плюс `report.json` с тем, что именно вышло.

---

## Шаг 4. Подкрутить под себя

**Другие шаблоны:**

```bash
python3 -m ytclip reels ... --templates glitch-cut,lyric-focus
```

**Спокойнее по эффектам:**

```bash
python3 -m ytclip reels ... --intensity 0.6
```

**Другой стиль субтитров:**

- `word-pop` — 2–4 слова крупно, спетое слово выпрыгивает (самый «тикток»);
- `line-karaoke` — видна вся строка, цвет сползает по словам;
- `line-fill` — видна вся строка, слова загораются по очереди.

**Перерендерить один клип, ничего не считая заново:**

```bash
python3 -m ytclip render work/nochnoy-reys/clip-02-glitch-cut.json --audio input/nochnoy-reys/track.mp3
```

---

## Шаг 5. Править саму графику

```bash
npm run studio --prefix remotion
```

В Studio видно анимацию покадрово. Файлы шаблонов — `remotion/src/templates/`.
Чтобы добавить свой, пройдите чек-лист из rules.md §9.

## Частые проблемы

| Симптом | Причина и что делать |
|---|---|
| `ffmpeg not found` | поставьте ffmpeg и убедитесь, что он в PATH |
| Remotion пытается скачать Chrome и падает | укажите браузер: `export REMOTION_BROWSER_EXECUTABLE=/путь/к/chrome` |
| Whisper не грузит модель | нужен доступ к `huggingface.co`; либо работайте с `--no-whisper` |
| Субтитры запаздывают на всём клипе | `--offset -0.2` |
| Субтитры разъезжаются к концу | тайминг по фразам слишком грубый — включите Whisper или поправьте `timing.lrc` |
| Движение графики мимо битов | темп определился неверно, проверьте `ytclip analyze` |
| Текст залезает на кнопки TikTok | уменьшьте текст или проверьте безопасные зоны (rules.md §3.3) |
| 3D-шаблон рендерится очень долго | это нормально при программном рендере; ставьте его одним клипом из четырёх |

## Сколько это занимает

На обычном процессоре, клип 22 секунды (660 кадров):

- `cover-pulse`, `lyric-focus`, `glitch-cut` — считанные минуты;
- `spectrum` — чуть дольше (много элементов);
- `vinyl-3d` — дольше всех, 3D считается на процессоре.

Анализ трека — несколько секунд. Whisper на модели `small` — примерно столько
же, сколько длится трек.

# YTclip&music

Трек + обложка + текст → несколько вертикальных клипов (9:16) для Reels, TikTok
и Shorts: графика в стиле обложки, движение в такт музыке и караоке-субтитры,
которые загораются ровно в момент пропевания слова.

Правила проекта и карта всех файлов — в **[rules.md](rules.md)**.

---

## Как это работает

```
трек.mp3 ─┬─> ffmpeg ──────> нарезка и финальный экспорт
          ├─> Whisper ─────> слова + таймкоды ─┐
          ├─> анализ numpy ─> биты, темп, хуки ┼─> clip.json ─> Remotion ─> reel.mp4
          └─> обложка.jpg ─> палитра ──────────┘
```

- **ffmpeg** — режет трек, сводит звук с картинкой, экспортирует.
- **Whisper** — распознаёт слова с таймкодами (опционально, см. ниже).
- **Анализ на numpy** — темп, биты, доли такта, энергия, где поёт голос, где
  припев. Без librosa — ставится куда угодно.
- **Remotion** — рисует анимацию: от простой графики до 3D-сцен.

## Установка

```bash
git clone https://github.com/flyboyhigh777-coder/YTclipand-music.git
cd YTclipand-music
```

```bash
pip install numpy pillow
```

```bash
npm install --prefix remotion
```

Нужен ещё **ffmpeg** (`apt install ffmpeg` / `brew install ffmpeg`) и
**Node.js 18+**.

Распознавание речи — по желанию:

```bash
pip install faster-whisper
```

Проверить, что всё на месте:

```bash
python3 -m ytclip doctor
```

## Быстрый старт

Положите материалы трека в папку и запустите один раз:

```bash
python3 -m ytclip reels input/мой-трек/track.mp3 --cover input/мой-трек/cover.jpg --lyrics input/мой-трек/lyrics.txt --title "Название трека" --artist "Название группы" --count 4
```

Готовые клипы появятся в `out/<название>/`, по правилу именования из rules.md §5.4.

Проверить конвейер на синтетическом примере, без своих файлов:

```bash
python3 examples/make_demo_assets.py
```

```bash
python3 -m ytclip reels assets/demo/demo-track.wav --cover assets/demo/demo-cover.jpg --lyrics assets/demo/demo-lyrics.txt --title "Неон над рекой" --artist "DEMO" --count 2
```

## Команды

| Команда | Что делает |
|---|---|
| `ytclip doctor` | проверяет ffmpeg, Node, Remotion, Chromium, Whisper |
| `ytclip analyze ТРЕК` | темп, биты, доля вокала, лучшие фрагменты |
| `ytclip hooks ТРЕК` | только список самых цепляющих кусков |
| `ytclip transcribe ТРЕК` | Whisper: слова с таймкодами в JSON |
| `ytclip align ТРЕК --lyrics ФАЙЛ` | сводит ваш текст с музыкой, выдаёт `.lrc` |
| `ytclip reels ТРЕК --cover ... --lyrics ...` | весь конвейер целиком |
| `ytclip render clip.json` | перерендерить один подготовленный клип |
| `ytclip templates` | список шаблонов |

Полезные флаги `reels`:

| Флаг | Смысл |
|---|---|
| `--count 4` | сколько клипов сделать |
| `--length 22` | длина клипа в секундах |
| `--templates cover-pulse,glitch-cut` | какие шаблоны использовать |
| `--captions word-pop` | стиль субтитров: `word-pop`, `line-karaoke`, `line-fill` |
| `--intensity 0.7` | сила эффектов (0 — спокойно, 1.5 — агрессивно) |
| `--offset -0.2` | сдвинуть субтитры раньше на 0.2 с |
| `--no-whisper` | не использовать распознавание |
| `--dry-run` | только подготовить `clip.json`, без рендера |

## Шаблоны

| Шаблон | Картинка |
|---|---|
| `cover-pulse` | обложка во весь экран, пульсирует в такт, зерно и виньетка |
| `lyric-focus` | крупный текст на живом градиенте из палитры обложки |
| `vinyl-3d` | 3D-сцена: обложка как вращающаяся пластинка под движущимся светом |
| `spectrum` | спектр-бары и обложка-карточка |
| `glitch-cut` | жёсткие склейки по тактам, RGB-сдвиг, вспышки — под сам хук |

## Если субтитры не попадают в слова

1. Запустите с `--dry-run` или возьмите готовый файл `work/<трек>/timing.lrc`.
2. Поправьте время строк руками (формат `[мм:сс.хх]`).
3. Передайте исправленный файл обратно: `--lyrics work/<трек>/timing.lrc`.

Или сдвиньте всё сразу: `--offset -0.25`.

## Предпросмотр и правка графики

```bash
npm run studio --prefix remotion
```

Откроется Remotion Studio, где видно анимацию в реальном времени. Чтобы
смотреть на своих данных, выберите композицию и подставьте
`work/<трек>/clip-01-*.json` через панель props.
